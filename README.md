**不适合的人：** 只追求极致低价、不在乎 IP 属性的普通 VPS 用途；需要大带宽大存储做媒体分发的；对大陆直连延迟要求极高又坚持选新加坡、英国节点的。

**优惠码能叠加年付折扣吗？**
能。年付本身 8 折，再叠加 9 折码，等效约 7.2 折。季付 9 折叠加后 8.1 折，二年付 7 折叠加后 6.3 折。结算页点验证后看总价变化最准。

**码是长期有效的吗？**

**特价年付版也能用吗？**
有评测说“所有 VPS 方案都能用”，但特价年付这条产品线是否全部参与叠加，没有逐条确认。买 466 元/年这类特价档时，以结算页验证结果为准。

**年付和月付哪个划算？**
以英国基础版为例，月付 68 元用码 61.2 元/月，一年约 734 元；直接买年付，标价本身已是折扣价，再用码更低。用量确定、打算长期用，年付明显省；只想试一两个月，月付更灵活。

**支持哪些付款方式？**
支付宝和微信支付可以确认。其他渠道在不同资料里说法不一致，以结算页实际显示的选项为准。

**买了不满意能退吗？**
官网承诺 48 小时内不满意无条件退款，超过 48 小时需要联系客服评估。部分住宅 VDS 属于特殊产品，只退网站余额，下单前看产品页说明。

**SSH 端口为什么不是 22？**
新机器端口随机分配，官方说明是防止 SSH 被扫、保护 IP 纯净度。开通后在控制面板查端口号，用分配到的端口连接。
